% They are self-consistent and physically plausible for a representative
% clinical scanner, but they are back-of-envelope, not measured, and carry no
% citation. The natural source is your own GATE/Geant4 model (see the Monte
% Carlo subsection of the literature review), which would make this an original
% figure rather than a redrawn textbook one.
%
% Assumed configuration: 20 cm patient, 80 cm ring diameter, 20 cm axial FOV,
% 20 mm LYSO, annihilation at the centre.
%
%   stage                    survival factor                    running total
%   emitted                  -                                  100.0 %
%   escapes body unscattered exp(-0.096 cm^-1 x 10 cm)  = 0.383   38.3 %
%   within solid angle       (L/2)/sqrt(R^2+(L/2)^2)
%                            = 10/sqrt(40^2+10^2)       = 0.243    9.3 %
%   interacts in crystal     1-exp(-0.87 cm^-1 x 2 cm)  = 0.824    7.7 %
%   passes energy window     ~0.60 (photofraction plus
%                            inter-crystal scatter)               4.6 %
%
% SPLIT WITHIN THE CRYSTAL STAGE (stated in the figure's footnote): of the
% photons that interact, ~32 % photoelectric / ~68 % Compton, the usual LYSO
% photofraction at 511 keV. Also unsourced -- the 0.60 above is NOT the same
% quantity: it is the photopeak fraction, which is higher than 0.32 because
% Compton events often deposit full energy via further interactions in the
% crystal. Do not "correct" one to match the other; they measure different
% things. BGO would be ~0.40 photoelectric, NaI ~0.17.
%
% Losses: 61.7 + 29.0 + 1.6 + 3.1 + 4.6 surviving = 100.0  (conserved)
%
% NOTE ON SCATTER: the 61.7 % dead-ends here, but those photons are NOT
% absorbed. At 511 keV in tissue photoelectric absorption is negligible, so
% essentially all of them Compton scatter and most escape the body; a good
% share reach the detector and pass the energy window (a 435-650 keV window
% accepts scatter up to ~35 deg, since E' = 511/(2-cos(theta))), and are
% recorded as scattered coincidences. What the scattering destroys is the LOR,
% not the photon. The trunk here tracks photons that keep a VALID LOR, which is
% why the survivor is labelled an unscattered single -- recorded singles are far
% more numerous. Routing scatter forward into the energy-window stage instead
% would be the fuller picture, at the cost of running the fattest band to the
% right edge (see the layout note below on why that was abandoned).
%
% NOTE ON PAIRS: this tracks ONE photon to a recorded single. A coincidence
% needs both. The per-photon terms square, but the solid-angle term does NOT:
% the photons are back-to-back, so if one clears the ring the other largely
% does too. Pair sensitivity ~ 0.243 x (0.383 x 0.824 x 0.60)^2 ~ 0.8 %, which
% is the ~1 % clinical figure. Squaring the geometric term would be wrong.
%
% ---------------------------------------------------------------------------
% GEOMETRY -- node/ribbon paths below are GENERATED, do not hand-edit them
% ---------------------------------------------------------------------------
% Standard Sankey layout: a node bar per stage, with ribbons splitting between
% them. Vertical scale 0.075 cm per %, five columns at x = 0, 2.2, 4.4, 6.6,
% 8.8, and a 0.40 cm gap between nodes sharing a column.
%
% Each loss TERMINATES at the stage that claims it and is labelled there. Only
% the surviving trunk carries on to the right. That is what stops the two fat
% losses (61.7 % and 29.0 %) from filling the canvas, which is what went wrong
% in earlier attempts that ran every band out to the right edge.
%
% Ribbons are cubic beziers with horizontal tangents, i.e. a pure vertical
% shear, so offsetting one vertically can never fold it no matter how thick it
% is. A swept circular arc (what the CTAN `sankey` package's \sankeyoutin
% produces) folds unless its radius exceeds half the band thickness, which the
% 61.7 % band at 4.6 cm thick cannot satisfy in the space available.
%
% To change the numbers, edit and re-run the generator, then paste its output
% over everything from \providecolor to \end{tikzpicture} -- and change the

%     thesis builds from this file alone, with no Python dependency)
